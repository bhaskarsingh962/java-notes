# 💾 Difference Between `List` and `ArrayList` in Java

---

## 🔹 1. Basic Definition

* **List** → Interface in `java.util`
* **ArrayList** → Class in `java.util` that implements `List`

```java
List<String> list;              // Interface reference
ArrayList<String> list2 = new ArrayList<>();  // Concrete implementation
```

---

## 🔹 2. Type

| Point                | List      | ArrayList      |
| -------------------- | --------- | -------------- |
| Type                 | Interface | Concrete Class |
| Can be instantiated? | ❌ No      | ✅ Yes          |

---

## 🔹 3. Declaration Example

```java
List<String> list = new ArrayList<>();  // ✅ Best practice
ArrayList<String> list = new ArrayList<>();  // Works, but less flexible
```

---

## 🔹 4. Purpose

* `List` defines *what operations* can be done (add, remove, get, etc.).
* `ArrayList` defines *how* these operations are performed (using a **dynamic array**).

---

## 🔹 5. Flexibility

* Using `List` reference makes code more flexible (supports polymorphism).

```java
List<String> list = new ArrayList<>();
list = new LinkedList<>(); // ✅ Easily switch implementation
```

---

## 🔹 6. Internal Data Structure

* `List` → Abstract (no internal structure)
* `ArrayList` → Uses **dynamic array**

---

## 🔹 7. Performance

| Operation               | ArrayList Time Complexity |
| ----------------------- | ------------------------- |
| Access by index         | O(1)                      |
| Insert/remove at end    | O(1) amortized            |
| Insert/remove in middle | O(n)                      |
| Search                  | O(n)                      |

---

## 🔹 8. Order & Duplicates

✅ Maintains insertion order
✅ Allows duplicate elements

```java
List<String> list = new ArrayList<>();
list.add("A");
list.add("B");
list.add("A");  // duplicate allowed
System.out.println(list); // [A, B, A]
```

---

## 🔹 9. Thread Safety

* `List` → Depends on implementation
* `ArrayList` → ❌ Not thread-safe

To make it thread-safe:

```java
List<String> syncList = Collections.synchronizedList(new ArrayList<>());
```

---

## 🔹 10. Return Type Example

```java
List<String> list = Arrays.asList("A", "B", "C");
System.out.println(list.getClass());
// Output: class java.util.Arrays$ArrayList (not java.util.ArrayList)
```

---

## 🔹 11. When to Use

| Situation                                  | Use         |
| ------------------------------------------ | ----------- |
| When you only need an interface            | `List`      |
| When you specifically need a dynamic array | `ArrayList` |

---

## 🔹 12. Summary Table

| Feature           | `List`                                | `ArrayList`                                         |
| ----------------- | ------------------------------------- | --------------------------------------------------- |
| Type              | Interface                             | Class                                               |
| Defined in        | `java.util`                           | `java.util`                                         |
| Instantiation     | ❌                                     | ✅                                                   |
| Implements        | —                                     | `List`, `RandomAccess`, `Cloneable`, `Serializable` |
| Data Structure    | Abstract                              | Dynamic Array                                       |
| Allows Duplicates | ✅                                     | ✅                                                   |
| Maintains Order   | ✅                                     | ✅                                                   |
| Thread-safe       | Depends                               | ❌                                                   |
| Performance       | Depends                               | Fast for access, slower for middle inserts          |
| Example           | `List<String> l = new ArrayList<>();` | `ArrayList<String> l = new ArrayList<>();`          |

---

## 🔹 13. Interview Tip 💡

> "`List` is an **interface** that defines the behavior of ordered collections,
> while `ArrayList` is a **class** that implements it using a dynamic array.
> We use `List` as the reference type for flexibility."

---

## ✅ Recommended Code Practice

```java
List<Integer> list = new ArrayList<>();
```
