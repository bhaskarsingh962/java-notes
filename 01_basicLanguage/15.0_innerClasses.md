## Why use an inner class?
To logically group classes only used in one place

To increase encapsulation (hiding classes inside another)

For event handling in GUI applications (common in anonymous inner classes)

## 📘 Inner Classes in Java (Interview Notes)

In Java, inner classes are classes defined inside another class.
They help in grouping classes that are logically related and make the code more readable & maintainable.

## ✅ 1. Member Inner Class (Non-static inner class)

🔹 A non-static inner class is defined inside another class but without the static keyword.
🔹 It has access to all instance variables & methods of the outer class (including private).
🔹 To create an object of the inner class, you first need an object of the outer class.

Example:
class Outer {
    private String message = "Hello from Outer!";

    // Non-static inner class
    class Inner {
        void showMessage() {
            System.out.println(message); // ✅ Can access outer instance variable
        }
    }
}

public class Test {
    public static void main(String[] args) {
        Outer outer = new Outer();            // Create outer object
        Outer.Inner inner = outer.new Inner(); // Create inner object
        inner.showMessage();  // Output: Hello from Outer!
    }
}


📌 When to use:

When the inner class is tightly bound to an object of the outer class.

Example: Iterator implementations inside Collection classes.

# inner class will behave like a member of a class 
# all the properties that can private can access inside inner class

## ✅ 2. Static Nested Class

🔹 Declared with static.
🔹 Can only access static members of the outer class directly.
🔹 Doesn’t need an outer class object to be instantiated.
🔹 can not access non static intences of outer class

Example:
class Outer {
    static String staticMsg = "Hello from Static Outer!";

    static void staticMethod() {
        System.out.println("Static method of Outer called!");
    }

    // Static nested class
    static class Inner {
        void display() {
            // ✅ Accessing outer static variable
            System.out.println(staticMsg);

            // ✅ Calling outer static method
            staticMethod();
        }
    }
}

public class Test {
    public static void main(String[] args) {
        Outer.Inner inner = new Outer.Inner(); // ✅ Direct creation, no outer obj
        inner.display();  // Output: Hello from Static Outer!
    }
}


📌 When to use:

When the inner class doesn’t need access to outer instance fields.

Example: Map.Entry in Java Collections.


## ✅ 3. Local Inner Class

🔹 A class defined inside a method.
🔹 It can access final or effectively final variables of the method.
🔹 Useful when you need a one-time helper class inside a method.

Example:
class Outer {
    void printMessage() {
        String localVar = "Local Inner Access!";

        // Local inner class
        class LocalInner {
            void display() {
                System.out.println(localVar); // ✅ can access final/effectively final vars
            }
        }

        LocalInner inner = new LocalInner();
        inner.display();
    }
}

public class Test {
    public static void main(String[] args) {
        Outer outer = new Outer();
        outer.printMessage(); // Output: Local Inner Access!
    }
}


📌 When to use:

When a class is needed only inside a specific method.

Keeps scope limited & code clean.


## ✅ 4. Anonymous Inner Class

🔹 A class without a name, usually used for instantiating interfaces or abstract classes on the fly.
🔹 Often used in event handling or when we need a one-time implementation.

Example with Interface:
interface Greeting {
    void sayHello();
}

public class Test {
    public static void main(String[] args) {
        Greeting g = new Greeting() {  // ✅ Anonymous inner class
            public void sayHello() {
                System.out.println("Hello from Anonymous Inner Class!");
            }
        };

        g.sayHello(); // Output: Hello from Anonymous Inner Class!
    }
}

Example with Abstract Class:
abstract class Animal {
    abstract void sound();
}

public class Test {
    public static void main(String[] args) {
        Animal dog = new Animal() {
            void sound() {
                System.out.println("Bark!");
            }
        };

        dog.sound(); // Output: Bark!
    }
}


📌 When to use:

For quick, one-time use implementations.

Very common in GUI (Swing/JavaFX) event listeners or multi-threading (Runnable).

🔑 Interview Pointers

Q: Why inner classes?
A: They provide better encapsulation, can logically group classes, and give cleaner, more maintainable code.

Q: Difference between static nested and non-static inner class?
A:

Static → Doesn’t require outer object, can only access static members.

Non-static → Needs outer object, can access both static & instance members.

Q: Why anonymous inner classes?
A: To quickly implement interfaces or abstract classes without writing full class definitions.
